# 球员贡献检测器方案 v1

> 设计日期：2026-06-05 | 状态：已落地

---

## 1. 设计目标

不再用"进球多=贡献大"的简单逻辑评价球员，而是从 **11 个现代足球分析角度** 出发，用代码对每名球员的所有 47 项统计数据做 Z-score 对比，识别出不同类型的关键贡献者。

### 1.1 设计哲学

- **代码做数学，LLM 做叙事** — 代码保证数据对比零错误，LLM 负责把结果翻译成球迷能读懂的语言
- **同队对比** — 大部分检测器在队内做 Z-score，因为不同球队的体系差异太大，跨队对比无意义
- **不只是绝对值** — 引入比率指标（传球成功率、抢断成功率等）和负向指标（被过人、回传过多等）

### 1.2 三层分工

```
Layer 1: 代码引擎 (src/engine/player_insights.py)
├── 对 47 项指标逐球员计算 Z-score、跨球员对比
├── 11 个检测器各自打分，输出 top-3 候选人
├── 去重后输出 ~10 名"焦点球员" + 触发角度 + 证据数据
└── 输出: 结构化 Result 对象

Layer 2: LLM 叙事 (temperature=0.7)
├── 输入: ~10 名焦点球员的摘要数据
├── 任务: 为每人写 2-3 句生动说明 + 一句话定调
└── 输出: 每人一段叙事文本

Layer 3: HTML 渲染 (build_report.py)
├── 卡片布局: 头像 | 姓名 | 位置 | 全部 47 项数据
├── 高亮触发指标的数值 + 角度标签
├── 事件加成徽章
└── 可复制粘贴到微信公众号
```

### D4 节奏控制 / 节拍器 (Tempo Control)
> 谁是球队的传球枢纽？球到他脚下最多、丢球最少、向前传最多

| 指标 | type_id | 计算方式 |
|------|--------:|------|
| 传球总数 | 80 | 球员传球 / 全队总传球 = 传球占比 |
| 准确传球 | 116 | 准确传/传球 = 准确率 |
| 传球成功率 | 1584 | 优于手算时使用 API 直接返回的 % |
| 三区传球 | 27269 | 三区/传球 = 向前倾向 |
| 触球 | 120 | 球员触球 / 全队触球 = 触球占比 |
| 回传 | 27272 | 回传/传球 = 回传倾向（负向） |

**公式**:
```
得分 = 传球占比 × 100
     + (准确率/100) × 2
     + 向前比 × 10
     + 触球占比 × 100
     − 回传比 × 5
```

| 指标 | type_id | 权重 |
|------|--------:|:---:|
| 抢断 | 78 | 1.0 |
| 拦截 | 100 | 1.0 |
| 球权回收 | 27271 | 1.0 |
| 封堵射门 | 97 | 0.8 |
| 解围 | 101 | 0.5 |
| 赢得对抗 | 106 | 0.6 |
| 被过人 | 110 | −0.5 |
| 被抢断 | 94 | −0.5 |
| 导致丢球的失误 | 571 | −2.0 |
| 导致射门的失误 | 48997 | −1.0 |

**计算**: 先分别算进攻分排名和防守分排名，再取调和均值：
```
双向分 = 2 × 进攻排名 × 防守排名 / (进攻排名 + 防守排名)
```
得分越低越好（排名越靠前），包含门将。

### D10 终结质量 (Finishing Quality)
> 不是谁射得多，而是谁的射门真正有威胁

| 子指标 | 计算方式 | 权重 | 说明 |
|--------|------|:---:|------|
| xG/射门 (非点球) | (xG − 点球数×0.76) / (射门 − 点球数) | 2.0 | 排除点球灌水 |
| 射正质量 | max(xGOT − xG, 0) | 1.5 | 射正后进球概率提升 |
| 实际终结 | 进球 − xGOT | 1.0 | 门将反应以外 |
| 射正率 | 射正 / 射门 | 1.0 | 至少打在门框内 |
| 射门表现 | 9685 (G−xG) | 1.5 | SportMonks 官方计算 |
| 中框 | 64 | 0.8 | 差一点运气 |

> 关键修正: 点球 xG≈0.76 会严重拉高 xG/射门。`xG/射门` 使用**非点球 xG / 非点球射门**，使运动战和点球得分者可公平对比。

### D11 xG 背离度 (xG Deviation)
> 实际进球 vs 期望进球，检测运气与实力

| 标签 | 触发条件 | 得分 |
|------|---------|:---:|
| 超预期终结者 | 进球 − xG ≥ 0.5 | abs(G−xG) |
| xG 欠债者 | xG ≥ 0.5 且 进球 = 0 | abs(G−xG) |
| 完美表现 | \|进球 − xG\| ≤ 0.15 且 进球 > 0 | abs(G−xG) |
| 浪射惩罚 | 射门 ≥ 3 且 xG < 0.3 且 进球 = 0 | abs(G−xG) |

## 4. 汇总去重策略

1. 每队每检测器取 Top 3
2. 跨检测器统计每个球员被命中的次数和累计得分
3. 按命中次数降序、累计得分降序排列
4. 达到 ≥2 次命中的球员进入"焦点球员"名单
5. 两队各至少 2 名球员入选
