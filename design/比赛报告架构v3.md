# 比赛报告架构 v3 — 三层洞察 × 六段叙事

> 设计日期：2026-06-04 | 状态：生产中 | 更新：2026-06-12
>
> **2026-06-12 更新**：新增统一报告生成器 `generate_match_report.py`，整合战术报告 V2 + 球员贡献 V6 为一次性输出。详见最后一节。

---

## 1. 设计目标

从 v2 的"信号驱动"进化为**三层洞察驱动的六段叙事**：

1. **观点先行** — 每段叙事有明确的论点，由数据支撑
2. **数据为证** — 硬事实代码计算，LLM 不能曲解
3. **叙事动人** — LLM 用生动语言表达，面向球迷 + 分析师双受众
4. **视角新奇** — 交叉对比 trends/events/stats 发现非显而易见的洞察

## 3. Layer 1: 硬事实计算 — `src/engine/cross_insights.py`

代码层计算的精确数值，LLM 可以引用但不可曲解。

### 3.1 控球有效性
- `xG / 控球率` — 每 1% 控球的期望进球产出
- 全场 + 分时段计算

### 3.2 射门转化曲线
- 每 15 分钟时间窗口的射门次数 + 射正率 + xG/射门
- 输出：`[{window: "0-15", shots: 3, sot: 1, xg_ps: 0.15}, ...]`

### 3.3 xG 背离度
- 实际进球 vs xG，标注超额方和超额幅度
- 输出：`{home_actual: 1, home_xg: 2.17, delta: -1.17, ...}`

### 3.4 攻势节奏差
- 上下半场各统计指标的斜率对比
- 输出：`{shots_slope_h1: 0.07, shots_slope_h2: 0.27, ratio: 3.9}`

### 3.5 时段主导权转移
- 每个 period 的控球率、射门占比、威胁进攻占比
- 标记主导权转换时刻（两队指标曲线交叉点）

### 3.6 防守强度衰减
- 抢断 + 拦截 per 15 分钟窗口
- 输出趋势 + 衰减率

### 3.7 传球网络特征
- 长传占比（长传/总传）、传中占比、关键传球率
- 双方对比 + 分时段对比

### 3.8 时间压迫
- 最后 15 分钟（含补时）的攻防比例变化
- 领先方是否鸣金收兵、落后方是否全线压上

### 3.9 球员效率
- 每分钟 xG、每脚射门 xG、射门转化率
- Top 3 + Bottom 3

### 3.10 换人效果 — `src/engine/sub_impact.py`
- 每次换人的**前后 15 分钟窗口**对比：
  - 球队控球率变化
  - 球队射门次数变化
  - 球队进攻次数变化
  - 球队被射门次数变化
- 换下球员的攻防数据 + 角色定位
- 教练换人意图推断
- 换人效果评分（有效/无效/中性）

## 5. Layer 3: 六段叙事模板

### 第一段【封面导语】
- **Temperature**: 0.75
- **叙事**：一句话定调 + 一段话概述
- **语言要求**：中性，点球获胜用"点球决胜"而非"续命"
- **数据支撑**：比分、xG、控球率、赛事背景
- **视觉**：mplsoccer 足球场俯视图（双方首发 11 人对位 + 球衣号 + 头像 + 替补 + 换人箭头）

### 第二段【比赛节奏 + 关键事件冲击】
- **Temperature**: 0.75
- **叙事**：trends 主线的节奏演变 + 标注关键事件
- **事件冲击分析**：
  - 进球：前后 15min 控球/射门变化，领先方是否保守
  - 换人：换下球员角色分析 → 教练意图 → 换上后效果（关联 sub_impact.py）
  - 红牌：少一人量化影响
  - 黄牌：是否导致同侧防守退缩
  - VAR：中断时长 + momentum 影响

### 第三段【效率悖论】
- **Temperature**: 0.75
- **叙事**：对比投入（控球/射门）和产出（进球/xG）
- **关键洞察**：谁浪费、谁高效得不正常

### 第四段【战术解码】
- **Temperature**: 0.75
- **叙事**：传球偏向、进攻通道、对抗分布、阵型
- **数据支撑**：长/短传比、传中偏好、head-to-head 对抗

### 第五段【人物志】
- **Temperature**: 0.75
- **叙事**：英雄 + 罪人 + 隐形人
- **数据支撑**：xG 贡献、评分、关键传球、致命失误

### 第六段【数据深潜】
- **Temperature**: 0.1
- **纯数据呈现**：分时段统计表 + 球员评分表 + 事件时间线 + xG 分布图
- **无叙事**：Markdown 表格 + 引用图片

## 6. LLM 调用策略

```
调用 1（Temperature 0.75）：
  输入：Layer 1 硬事实 + Layer 2 信号 + events/timeline 摘要 + trends 关键点
  输出：第一～五段（叙事文本，【标题】标记分段）

调用 2（Temperature 0.1）：
  输入：分时段统计表 + 球员评分表 + events 摘要
  输出：第六段（纯 Markdown 表格）
```

两调用并行或串行（取决于 LLM API 限制）。

## 7. 报告最终输出

### report.md / report.html 结构
```
封面导语段（LLM 叙事）
+ 首发阵容可视化图（mplsoccer PNG）
  ├── 足球场俯视图（双方 11 人对位）
  ├── 球员头像 + 球衣号 + 姓名 + 位置
  ├── 替补席（标注换上/换下箭头）
  └── 顶部横幅（赛事 + 阶段 + 球场）
+ 比赛节奏段 + 关键事件冲击（LLM 叙事）
  └── 嵌入 mommentum 图
+ 效率悖论段（LLM 叙事）
+ 战术解码段（LLM 叙事）
  └── 嵌入 pass_network 图
+ 人物志段（LLM 叙事）
  └── 嵌入 radar 图 + subs 图
+ 数据深潜段（LLM 生成表格）
  ├── 分时段统计表
  ├── 球员评分表
  ├── 事件时间线表
  └── 嵌入 shots + xg_hist 图
```

## 10. 统一报告生成器 (2026-06-12 新增)

### 10.1 入口

```bash
# ★ 推荐：一次性生成战术报告 V2 + 球员贡献 V6
python generate_match_report.py 19683241

# 跳过 LLM（仅数据 + 图表）
python generate_match_report.py 19683241 --no-llm

# 仅生成战术报告
python generate_match_report.py 19683241 --tactical-only

# 仅生成球员卡片
python generate_match_report.py 19683241 --cards-only
```

### 10.2 管线架构

```
generate_match_report.py <match_id>
  │
  ├─ 数据层
  │   ├─ load_match_data() → 优先 data/raw/{id}/raw_data.json
  │   └─ compute_full_score() → 全场比分（常规 + 加时 + 点球）
  │
  ├─ 管道 B: 球员贡献检测器 V6
  │   ├─ run_v6(raw) → 七维贡献向量 + LLM 角色分析
  │   ├─ JSON → data/computed/{id}_players_v6.json
  │   └─ Excel → data/computed/{id}_players_v6.xlsx
  │
  ├─ 管道 A: 战术报告 V2
  │   ├─ compute_tactical_analysis(raw) → 四层因果模型
  │   ├─ LLM 战术叙事 (五段式)
  │   ├─ generate_all_tactical_charts() → 雷达/控球/射门/PPDA
  │   ├─ 事件时间轴 + 阵容图 (HTML + PNG)
  │   ├─ JSON + Excel → output/{id}_.../tactical_analysis.*
  │   └─ HTML → output/{id}_.../tactical_report.html
  │
  └─ 管道 C: 球员卡片 (需 --cards-only)
      └─ Playwright → output/{id}_.../player_cards/*.png
```

### 10.3 输出目录

```
output/{match_id}_{HOME}_vs_{AWAY}/
├── tactical_report.html          # ★ 主力产品：战术分析报告 V2
├── tactical_analysis.json        # 战术数据结构
├── tactical_analysis.xlsx        # 战术 Excel
├── images/
│   ├── tactical_radar.png        # 战术雷达图
│   ├── tactical_shots.png        # 时段射门分布
│   ├── tactical_ppda.png         # 压迫强度对比
│   ├── tactical_possession.png   # 控球摇摆图
│   ├── lineup.png               # 阵容图
│   └── timeline.png             # 事件时间轴
├── compare/                      # 球员对比图
└── player_cards/                 # 球员贡献卡片

data/computed/
├── {match_id}_players_v6.json    # 球员贡献原始数据
└── {match_id}_players_v6.xlsx    # 球员贡献 Excel
```

### 10.4 与旧版 run.py 的关系

| | `generate_match_report.py` | `run.py` |
|---|---|---|
| 战术报告 | V2 (四层因果 + 五段叙事) | 旧版（信号驱动六段叙事） |
| 球员分析 | V6 (七维贡献 + 角色推断) | 无 |
| 输出格式 | HTML (tactical_report.html) | HTML + Markdown |
| 战术图表 | 4 张 (雷达/控球/射门/PPDA) | 7 张（效率/动量/传球网络等） |
| 推荐场景 | **日常生产** | 需要旧版报告格式时 |
