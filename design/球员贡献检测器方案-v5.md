# 球员贡献检测器方案 v5 — 七维贡献模型

> 设计日期：2026-06-08  |  状态：待审查
>
> **核心理念**：66 项 SportMonks 球员级指标全覆盖，按贡献方向归为 7 大类，每类用 Z-score 综合评分。
>
> 指标映射参考：[SportMonks统计指标全集.md](./SportMonks统计指标全集.md)

---

## 1. 设计目标

不再用"进球多=贡献大"的简单逻辑评价球员。从 **6 个外场贡献维度 + 1 个门将维度** 出发，对每名球员的 59 项外场指标做 Z-score 综合评分 + 标签分类，识别出不同类型的关键贡献者。

### 1.1 与旧版 v3 的主要区别

| | v3 | v5 |
|------|------|------|
| 指标覆盖 | 49/66 (74%) | **66/66 (100%)** |
| 检测器数量 | 13 个独立检测器 | **6 大类 + 关键事件 + 门将** |
| 分类逻辑 | 分散的"你有没有这个特质" | 聚焦的"你的贡献属于哪一维" |
| 指标重叠 | 大量指标跨检测器重复 | 每指标有主类别归属 |
| 门将 | 跳过 | C7 四维独立评估 |

### 1.2 设计哲学

- **队内 Z-score 对比** — 大部分检测器在队内做标准化，因为不同球队体系差异太大
- **综合评分而非单一指标** — 每个类别是多指标加权合成，权重反映在该维度中的相对重要性
- **正负双向** — 负面指标（被过人/失误/犯规等）权重为负数，自动降低综合分
- **C6 事件驱动** — 制胜球/绝杀等不是统计数据层面能捕捉的，需要解析 events 时间线

## 2. 核心算法：Z-score 综合评分 (zscore_composite)

### 2.1 直观理解

Z-score 回答的是：**在这个队里，你比平均水平强多少？**

```
某球员 Z-score = (该球员的值 - 全队均值) ÷ 全队标准差

Z > 0 = 高于队内平均水平
Z < 0 = 低于队内平均水平
Z = 0 = 正好是队均
```

### 2.2 三步走

**Step 1** — 对每个指标算队内 Z-score。
以解围为例，5 名球员：[4, 3, 1, 0, 0]，均值=1.6，标准差≈1.8：

| 球员 | 解围 | Z-score | 含义 |
|------|:---:|:---:|------|
| A | 4 | +1.33 | 远高于队友 |
| B | 3 | +0.78 | 高于队友 |
| C | 1 | -0.33 | 略低于队友 |
| D, E | 0 | -0.89 | 远低于队友 |

**Step 2** — Z-score × 权重 = 该指标的贡献分。

**Step 3** — 求和 = 维度综合分：
```
综合分 = Σ (每个指标 Z-score × 权重)
```

### 2.3 为什么不用原始值直接加

| 问题 | Z-score 如何解决 |
|------|------|
| 进球(1-2个)和传球(几十次)量纲不同，传球天然碾推进球 | 统一到"标准差"尺度上 |
| 全队之间，绝对值的比较无意义 | 队内标准化，公平对比 |
| 某队大胜 5-0，所有人都高分 vs 某队 1-0 死守 | 各自在队内排名，互不影响 |

### 2.4 代码参考

```python
def zscore(values):
    mean = sum(values) / len(values)
    std = math.sqrt(sum((v-mean)**2 for v in values) / len(values))
    return [(v - mean) / std for v in values]

def zscore_composite(players, metrics):
    """
    metrics: {label: (type_id, weight), ...}
    返回: [(name, score, {label: {'raw':, 'z':, 'contrib':}})]
    """
    scores = {p.name: 0.0 for p in players}
    for label, (tid, weight) in metrics.items():
        raw = [p.sv(tid) for p in players]
        zs = zscore(raw)
        for i, p in enumerate(players):
            scores[p.name] += zs[i] * weight
    return sorted(scores.items(), key=lambda x: -x[1])
```

## 5. C7 — 守门员贡献 (Goalkeeper Contribution)

> **标签**：`叹息之墙` / `稳定输出` / `脚下有雷`
> **回答**：门将对比赛结果有多大影响？
> **适用范围**：仅 position_id=24 的门将
> **特殊**：不用 Z-score（每场只有 2 名门将），改用 per-90 速率 + 双方直接对比

### 5.1 四维度模型

| 维度 | 权重 | 核心问题 |
|------|:---:|------|
| 扑救质量 | 40% | 他挡住了多少必进球？ |
| 禁区控制 | 30% | 他能统治小禁区空域吗？ |
| 出球参与 | 20% | 他是出球体系的起点还是短板？ |
| 失误惩罚 | 10% | 他的失误直接导致了什么后果？ |

### 5.2 维度详解

#### 扑救质量 (40%)

| type_id | 字段 | 说明 | 用法 |
|--------:|------|------|------|
| 57 | `saves` | 扑救 | per-90 |
| 104 | `saves_inside_box` | 禁区内扑救 | per-90 × 1.5（更难） |
| 1535 | `goalkeeper_goals_conceded` | 门将失球 | 分母 |

```python
扑救分 = (saves + saves_inside_box × 1.5) / max(goalkeeper_goals_conceded, 1)
```

零封 → 分母为 1，扑救全算净加分。扑救多+失球少=高分。

#### 禁区控制 (30%)

| type_id | 字段 | 说明 | 权重 |
|--------:|------|------|:---:|
| 584 | `good_high_claim` | 成功摘高球 | **1.5** |
| 103 | `punches` | 门将击球 | 1.0 |
| 107 | `aerials_won` | 赢得空中对抗 | 0.8 |
| 101 | `clearances` | 解围（出击清球） | 0.5 |

> 摘高球是制空统治力的最佳指标——拿住 > 打出。

```python
禁区控制分 = (good_high_claim×1.5 + punches + aerials_won×0.8 + clearances×0.5) / 90 × minutes
```

#### 出球参与 (20%)

| type_id | 字段 | 说明 | 权重 |
|--------:|------|------|:---:|
| 1584 | `passes_accuracy` | 传球成功率 % | 0.4 |
| 116 | `passes_accurate` | 准确传球 | 0.3 |
| 123 | `long_balls_won` | 成功长传 | 0.2 |
| 27270 | `long_balls_won_pct` | 长传成功率 % | 0.1 |
| 27273 | `possession_lost` | 丢失球权 | **-0.3** |

```python
出球分 = (passes_accuracy×0.4 + passes_accurate×0.3/90 + long_balls_won×0.2/90
          + long_balls_won_pct×0.1/100 - possession_lost×0.3/90) × minutes / 90
```

#### 失误惩罚 (10%)

| type_id | 字段 | 说明 | 扣分 |
|--------:|------|------|:--:|
| 571 | `error_lead_to_goal` | 导致丢球 | **-5.0** |
| 48997 | `error_lead_to_shot` | 导致射门 | **-2.0** |

```python
失误分 = error_lead_to_goal × (-5.0) + error_lead_to_shot × (-2.0)
```

### 5.3 综合评分

```python
综合分 = 扑救分×0.40 + 禁区控制分×0.30 + 出球分×0.20 + 失误分×0.10
```

### 5.4 标签规则

| 条件 | 标签 |
|------|------|
| 综合分 ≥ 对手 × 2 | `叹息之墙` |
| 失误分 < -1 且 出球分 < 0 | `脚下有雷` |
| 其余 | `稳定输出` |
| goals_conceded = 0 | 追加 `零封` |

## 9. 已知限制

| 问题 | 影响 | 建议 |
|------|------|------|
| Z-score 被极端值影响 | 一人独大时全队 Z 值偏低 | 可尝试剔除 outlier |
| 出场时间短的球员 | 数据基数小，Z-score 可能失真 | 出场 < 15 分钟跳过 |
| C3 含门将 | 门将传球模式与外场不同 | C3 中门将的 label 单独处理 |
| C6 事件分析依赖 events 数据完整 | 缺少 events 时 C6 只有 stats 部分 | 降级为纯 stats 评分 |
| 长传成功率为 0 的球员 | 4 项长传指标均为 0 | Z-score 不影响——0 就是队均附近 |
