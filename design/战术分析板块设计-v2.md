# 比赛战术分析板块设计 v2 — 因果分层模型

> 设计日期：2026-06-08 | 数据来源：SportMonks V3 球队级 45 项 + 球员级 66 项
>
> **v1 核心问题**：将「战术选择」（进攻体系/防守体系）与「数据结果」（控球效率/对抗强度）混为同级维度。控球效率和对抗强度是教练战术选择后产生的数据结果，而非战术本身。

---

## 1. 核心洞察

```
v1 的六维：  进攻体系 | 防守体系 | 控球效率 | 对抗强度 | 节奏管理 | 教练博弈
                      ↑_______________↑
                      这些都是"战术执行效果"，不是"战术选择本身"

v2 的因果链：

  战术选择（教练意图）
       ↓
  比赛走势（场上实际发生了什么）
       ↓
  数据结果（控球率 / xG / 对抗 / 传球分布）
       ↓
  效果判定（战术奏效了？被克制了？走偏了？）
```

**一句话总结**：先看教练想干什么，再看场上实际发生了什么，最后判断他的想法有没有落地。

## 4. Layer 1：战术选择 — 教练想干什么？

> **本质**：从数据反推教练赛前的战术意图。不是评价好坏，只是还原画像。
>
> ⚠️ **判定原则**：不使用绝对阈值（如"长传比 > 0.20"），因为不同比赛的数据量级差异巨大——英超的快节奏 vs 西甲的控球局，同样的 0.20 含义完全不同。改用 **比赛内双方对比（match-relative）**：只有当一支队的某项指标相比对手有显著差异时，才为其打上对应的战术标签。如果双方接近，则判定为"相似风格"。

### 判定哲学：Match-Relative（比赛内相对）

```
判断逻辑层：

Step 1 — 计算双方在同一场比赛中的指标值
  主队长传比 = 0.24,  客队长传比 = 0.09
  → 比例差异 = 0.24 / 0.09 = 2.67 倍

Step 2 — 差距显著且有最低基线？
  差距 > 1.5 倍 且 高的一方 > 最低基线（防止 0.04 vs 0.02 这种无意义对比）
  → 是 → 给高的一方打对应标签

Step 3 — 差距不显著？
  → 双方共享同一标签或都不打标签
  → "双方均偏向 X" 或 "无明显偏向"

这样：
  主队 0.24 vs 客队 0.09 → 差距 2.67x → 主队"长传急攻"，客队"短传控制"
  主队 0.22 vs 客队 0.20 → 差距 1.1x  → 双方"长传对攻"
  主队 0.06 vs 客队 0.05 → 差距 1.2x  → 双方"短传控制"
```

### 4.1 建攻模式 (Build-Up Mode)

用传球结构反向推断球队选择了怎样的进攻推进方式。**所有判定基于 match-relative 对比**。

```
指标计算：
  长传比 = long_balls / passes_total
  传中比 = crosses / passes_total
  进攻三区传球比 = passes_final_third / passes_total
  向前传球比例 = (passes_final_third + long_balls_won) / passes_total

Match-Relative 分类规则（以 Gap = 高方÷低方，Min = 低基线）：

  ┌──────────────┬──────────┬───────────┬──────────────────────────────────┐
  │ 指标          │ Gap 阈值  │ 最低基线   │ 标签分配                          │
  ├──────────────┼──────────┼───────────┼──────────────────────────────────┤
  │ 长传比        │ > 1.5x   │ 高方>0.15 │ 高方→"长传急攻"，低方→"短传控制"    │
  │ 长传比        │ ≤ 1.3x   │ —         │ 双方都高(>0.18)→"长传对攻"         │
  │               │          │           │ 双方都低(<0.12)→"短传互控"         │
  │ 传中比        │ > 1.5x   │ 高方>0.08 │ 高方→"边路传中"                    │
  │ 传中比        │ ≤ 1.3x   │ 双方>0.08│ "传中对决"                         │
  │ 进攻三区传球比│ > 1.7x   │ 高方>0.18 │ 高方→"中路渗透"（前提：长传比不极端）│
  │ 向前传球比    │ > 1.4x   │ 高方>0.25 │ 高方→"快速转换"                    │
  └──────────────┴──────────┴───────────┴──────────────────────────────────┘
  
  不满足以上任一 → "混合推进"

标签不互斥，一支队可以同时打上"边路传中"+"快速转换"。
```

### 4.2 防守姿态 (Defensive Posture)

从防守数据反向推断教练的防守部署。**PPDA 是核心判定指标**。

#### PPDA — 压迫强度金标准

> PPDA = Passes Per Defensive Action。衡量"对手每传多少脚球，我就进行一次防守动作"。数值越低，压迫越凶狠。

```
PPDA = 对手传球次数 / (本方抢断 + 拦截 + 犯规)

SportMonks 数据来源：
  对手传球 = 对方球队 type_id=80 (passes_total)
  本方抢断 = type_id=78 (tackles_total)
  本方拦截 = type_id=100 (interceptions)
  本方犯规 = type_id=56 (fouls_committed)

PPDA 区间映射：
  < 4     → 极高压迫——"利物浦/拜仁式窒息"
  4 - 7   → 高压迫——"前场疯狂逼抢"
  7 - 12  → 中等压迫——"选择性地施加压力"
  12 - 18 → 低压迫——"退守为主但不放弃中场干扰"
  > 18    → 蹲坑——"基本上放弃前场逼抢，退守禁区"
```

**PPDA 的优势**：相比单纯看抢断次数，PPDA 隐含了**防守主动性**——抢断多可能是因为球一直在你这边、对手进攻次数多，而 PPDA 把抢断和"对手掌控球权的时间"关联起来。面对高控球的传控队时，你的 PPDA 能说明你的压迫有没有破坏对方节奏；面对低控球的防反队时，你的 PPDA 能说明你是否在主动出击。

#### 防守姿态综合判定

和建攻模式一样，**防守姿态也用 match-relative 对比**——不是"你的 PPDA 是 6 所以你是高压迫"，而是"你的 PPDA 比对手低得多，在这场比赛里你是压迫方"。

```
Match-Relative 防守分类（PPDA Gap = 高方÷低方）：

  PPDA Gap > 2.5x 且 低方 < 8   → 低方→"极高压迫"，高方→"收缩蹲坑"
  PPDA Gap > 1.8x 且 低方 < 12   → 低方→"高位压迫"，高方→"蹲坑防守"
  PPDA Gap ≤ 1.4x                 → "双方防守策略相似"
                                   ├ 双方 PPDA < 8   → "高压对轰——两队都不退让"
                                   ├ 双方 PPDA 8~15  → "中场缠斗——互相试探"
                                   └ 双方 PPDA > 15  → "互蹲——谁也不愿意先出手"

辅以交叉验证（不变）：
  越位陷阱活跃度 = 对手越位次数
  抢断位置分布 = 中前场球员抢断 / 全队抢断
  解围倾向 = clearances / 对手射门次数
```

### 4.3 节奏策略 (Tempo Strategy)

从传球节奏推断教练设定的比赛速度。**同样使用 match-relative 对比**。

```
指标计算：
  每射门传球数 = passes_total / max(shots_total, 1)
  Gap = 高方每射门传球数 / 低方每射门传球数

Match-Relative 节奏分类：
  Gap > 2.0x 且 低方 < 20  → 低方→"高速转换——三传两递就到门前"
                             高方→"慢节奏——耐心传导猎杀空间"
  Gap > 2.0x 且 低方 ≥ 20  → "双方节奏适中，但一方明显更耐心"
  Gap ≤ 1.5x                → "双方节奏接近"
                              ├ 双方 < 20 → "快节奏对攻——都不拖泥带水"
                              ├ 双方 20~35 → "中速推进——有耐心但不拖沓"
                              └ 双方 > 35 → "慢节奏博弈——都在等待最好的机会"
```

**为什么 match-relative 在这里尤其重要**：一支控球 65% 的强队可能传球 500 次才射 12 次门（每射门 41.7 次传球），对弱队这很正常——他们就是慢节奏传控。但如果对手只有 280 次传球就射门 15 次（每射门 18.7 次传球），match-relative 会揭示："虽然双方都在自己的节奏里，但客队的进攻直接度是主队的 2.2 倍"。固定阈值会错过这个对比张力。

### 4.3.1 战术一致性验证 — 用 trends 区分「意图」与「反应」

> ⚠️ **当前 4.1-4.3 的最大盲区**：所有判定基于全场总计数据。一支全场长传比 0.24 的队伍被判为"长传急攻"——但如果他们 0-30 分钟长传比 0.08，60-90 分钟长传比 0.40，那他们不是"选择了长传急攻"，而是**落后之后被迫大脚向前**。这不是战术选择，这是场上反应。
>
> trends 逐分钟数据可以按窗口切片，计算每个窗口的指标值，然后对比窗口间的一致性。

#### 窗口粒度选择：分层策略

不是一刀切的 15 分钟。根据 trend 数据密度分两层：

```
窗口大小不取决于"我们想要多细"，而取决于数据本身的最小统计量够不够：

  高频指标（trends 几乎每分钟都有累积更新）：
    传球(80): 70-79 pts, 长传(62): 63-66 pts, 控球率(45): 48 pts, 进攻(43): 59-83 pts
    → 5 分钟窗口，9 段（0-5, 5-10, ..., 40-45, 45-50, ..., 85-90）
    → 每段有足够的累积值差分，不依赖事件频率
    → 用途：精准捕捉长传比变化、控球主导权切换

  低频指标（trends 每 5-10 分钟才更新一次累积值）：
    抢断(78): 18-19 pts, 拦截(100): 8-12 pts, 犯规(56): 11-17 pts, 射门(42): 7-19 pts
    → 15 分钟窗口，6 段（0-15, 15-30, 30-45, 45-60, 60-75, 75-90）
    → 若用 5 分钟则 18 段中 5-8 段防守动作=0，PPDA 分母为零；射门同理
    → 用途：PPDA、射门率、对抗频率
```

#### 核心逻辑

```
真正的战术选择 = 全场一致性高（教练赛前部署的，不会随比分轻易改变）
被动的场上反应 = 全场一致性低（指标值随比赛走势漂移，说明是临时应对）

一致性量化：用窗口值的变异系数（CV = σ / μ）

  CV < 0.25   → "高度一致——开场就确定的战术选择"
  CV 0.25~0.50 → "有一定波动——战术框架存在但受比赛走势影响"
  CV > 0.50   → "波动剧烈——这不是战术选择，是场上临时应对"
```

#### 各维度的一致性验证

```
建攻模式一致性（5 分钟窗口，trends type_id=62/80）：
  9 个窗口的 long_ball_ratio
  → [0.08, 0.09, 0.07, 0.10, 0.09, 0.12, 0.18, 0.22, 0.24]
  → CV = 0.48 → 不是"长传急攻"战术选择，是落后后的渐近反应

防守姿态一致性（15 分钟窗口，trends type_id=80/78/100/56）：
  6 个窗口的 PPDA
  → [4.2, 4.5, 3.8, 4.1, 4.3, 3.9]
  → CV = 0.06 → 高度一致，真正的"高位压迫"战术选择

  → [12.3, 11.8, 7.2, 5.1, 4.8, 4.5]
  → CV = 0.40 → 开始时并不压迫，随着落后追分逐步加码——这是反应，不是选择

节奏一致性（5 分钟窗口 for 传球/控球, 15 分钟窗口 for 射门）：
  15 分钟窗口的 passes_per_shot
  → CV < 0.25 → 节奏策略是真实的战术选择
  → CV > 0.50 → 节奏随比赛走势大幅摆动，没有固定的节奏策略
```

#### 对战术画像的修正

```
当 CV > 0.40 时，该维度的 match-relative 标签打上"疑似"前缀：
  "长传急攻（疑似反应性）"——说明数据上看是这样，但不一定是教练赛前部署的

LLM 叙事中体现：
  "主队的全场长传比达到 0.24，但这个数字从上半场的 0.08 飙升到
   下半场的 0.40——他们不是在踢长传急攻，而是在追赶比分中一步步
   放弃了中场过渡。这不是战术选择，这是战术破产后的条件反射。"
```

#### trends 所需数据

```
所有 type_id 已在 5.1/5.2 中验证（fixture 19683241 实测可用）：

  建攻一致性: 62 (Long Balls), 80 (Total passes), 98 (Crosses)
  防守一致性: 78 (Tackles), 100 (Interceptions), 56 (Fouls), 80 (对手 passes for PPDA)
  节奏一致性: 80 (passes), 42 (Total Shots)
  控球一致性: 45 (Ball Possession)

窗口切分：0-15, 15-30, 30-45, 45-60, 60-75, 75-90（同 5.1 进阶部分）
```

### 4.4 战术画像输出 — 双重模式

战术画像采用**代码计算 + LLM 叙事**的双重模式：

#### 4.4.1 代码层输出（结构化数据，供下游计算）

代码负责计算所有原始值和 match-relative 对比关系，输出结构化数据给**克制矩阵、效果判定、时段对比**等下游使用。**代码不做定性描述**——不再输出"短传控制"这类固定标签字符串。

```json
{
  "home_tactical_raw": {
    "long_ball_ratio": 0.09,        "cross_ratio": 0.06,
    "final_third_pass_ratio": 0.22,  "forward_ratio": 0.28,
    "passes_per_shot": 38.2,         "ppda": 4.8,
    "high_press_ratio": 0.62,        "clearance_ratio": 0.6
  },
  "away_tactical_raw": {
    "long_ball_ratio": 0.24,        "cross_ratio": 0.11,
    "final_third_pass_ratio": 0.14,  "forward_ratio": 0.38,
    "passes_per_shot": 14.5,         "ppda": 18.3,
    "high_press_ratio": 0.18,        "clearance_ratio": 2.1
  },
  "match_relative": {
    "long_ball_gap": 2.67,           "cross_gap": 1.83,
    "final_third_pass_gap": 0.64,    "forward_ratio_gap": 1.36,
    "passes_per_shot_gap": 2.63,     "ppda_gap": 3.81,
    "high_press_gap": 3.44,          "clearance_gap": 3.50
  }
}
```

#### 4.4.2 LLM 层输出（自然语言叙事，面向读者）

将上述原始值 + 对比表 + 比赛背景输入 LLM，让 LLM 用自己的语言描述双方的战术画像。**不预设固定标签，每场比赛生成独一无二的描述**。

**Prompt 输入（喂给 LLM 的数据）**：

```
【比赛背景】
{home} vs {away} | {league} | 比分 {score}

【双方传球结构对比（match-relative）】
          主队    客队    Gap(倍数)
长传占比   0.09   0.24   2.67x  ← 客队长传是主队的近3倍
传中占比   0.06   0.11   1.83x  ← 客队边路传中频率明显更高
三区传球   0.22   0.14   1.57x  ← 主队更多推进到进攻三区
向前传球   0.28   0.38   1.36x  ← 客队向前的欲望更强
每射传球   38.2   14.5   2.63x  ← 主队需要38脚传球才射一次，客队只需15脚

【防守姿态对比（PPDA）】
          主队    客队    差距
PPDA      4.8    18.3   3.81x  ← PPDA越低压迫越强，主队压迫强度是客队近4倍
高位抢断   0.62   0.18   3.44x  ← 主队62%的抢断发生在前场，客队只有18%
解围倾向   0.6    2.1    3.50x  ← 客队每次对手射门解围2.1次（蹲坑信号）

【比赛走势线索】
- 主队控球 {possession}%，总传球 {passes} 次
- 上半场射门比 {1H_shots_h}:{1H_shots_a}，下半场 {2H_shots_h}:{2H_shots_a}
- PPDA 时段变化：主队 1H {ppda_1h} → 2H {ppda_2h}（衰减{decay}%）
```

**LLM 输出约束**（写在 system prompt 中）：

```
你是一位足球战术分析师。请根据以上数据，用 120-180 字描述这场比赛的战术对决画像。

要求：
1. 给出双方战术特征的概括，不使用"长传急攻""高位压迫"等固定术语——
   用你自己的语言描述（比如不说"长传急攻"，而说"客队几乎不通过中场过渡，
   用长传直接寻找锋线"）
2. 使用具体的数字（长传比、PPDA、Gap 倍数等），让描述有数据支撑
3. 点明双方的战术对立面（一方在做什么，另一方在反做什么）
4. 风格：专业但可读，有画面感，像好的体育评论

禁止：贴标签、罗列数据、使用"长传急攻/短传控制/高位压迫/收缩蹲坑"等套话
```

**LLM 输出示例**（两种不同比赛的对比）：

输入一场"传控 vs 防反"的比赛：
> 主队的足球哲学写在传球数上——全场 523 脚传球，每 38 脚才转化为一次射门。他们不急于刺出致命一击，而是用传球慢慢收紧包围圈，62% 的抢断发生在前场说明丢球后的反抢几乎成了肌肉记忆。但 PPDA 从上半场的 4.2 跌到下半场的 7.1——这台高压机器的电池只撑了 45 分钟。客队则选择了完全相反的生存策略：每 15 脚传球就拔剑，长传占比是主队的近 3 倍，用最少的触球换取最大的纵深。他们不在中场恋战，解围 28 次的数据说明禁区就是最后的防线。

输入一场"镜像对决"的比赛：
> 两支球队仿佛共享同一套战术笔记本。双方的传球结构几乎镜像对称——长传比差距仅 1.1 倍，每射门传球数都在 18 次左右，连 PPDA 都不相上下（6.2 vs 6.8）。这不是一场"风格碰撞"的比赛，而是一场"看谁执行得更好"的比赛。唯一的微妙差异在于传中倾向——主队 0.10 的传中比略高于客队的 0.07，暗示着左路的 Hakimi 正在被反复激活。

输入一场"强弱悬殊"的比赛：
> 强弱分明的比赛往往不产生战术张力——强队用 65% 的控球和 0.08 的长传比控制全场，弱队用 PPDA 22.4 的蹲坑等待比赛结束。这场也不例外。但数据中有一个反常信号：弱队虽然 PPDA 极高（压迫意愿近乎为零），但每射门仅需 17 脚传球——说明一旦拿到球，他们选择用最直接的方式向前，哪怕这种方式成功率不高。

## 5. Layer 2：比赛走势 — 场上实际发生了什么？

> **本质**：战术选择之后的场上演化。战术随时可能被对手、事件、体能改写。

### 5.1 时段节奏分布

> 指标后的判定规则见下文。**固定阈值不适用**——下半场加速率需要 match-relative + 低基数过滤 + 比分感知。

#### 数据来源：SportMonks periods.statistics

实测 fixture 19683241（PSG vs Arsenal，含加时+点球大战），periods 数组结构：

```
periods = [
  {sort_order:1, description:"1st-half",   period_length:45,
   home_stats: {Total Shots:6, Total passes:345, Tackles:7, Interceptions:3, Fouls:4, ...},
   away_stats: {Total Shots:3, Total passes:105, Tackles:4, Interceptions:9, Fouls:5, ...}},
  {sort_order:2, description:"2nd-half",   period_length:45,  home_stats:{...}, away_stats:{...}},
  {sort_order:3, description:"extra-time", period_length:30,  home_stats:{...}, away_stats:{...}},
  {sort_order:5, description:"penalties",  period_length:0,   home_stats:{}, away_stats:{}},  // 空
]
```

> ⚠️ 加时赛描述不固定：有的是 `"extra-time"`（合并为一段 30 分钟），有的是 `"ET_1ST_HALF"` + `"ET_2ND_HALF"`（拆为两段 15 分钟）。代码需同时处理。

所需指标在各 period 的 `home_stats`/`away_stats` 中均可获取：

| 指标 | period stats key | 用途 |
|------|------|------|
| 射门 | `Total Shots` | 加速率分子 |
| 传球 | `Total passes` | PPDA 分母 |
| 抢断 | `Tackles` | PPDA 分子 |
| 拦截 | `Interceptions` | PPDA 分子 |
| 犯规 | `Fouls` | PPDA 分子 |

#### 计算逻辑（含加时赛）

```
常规时间：
  1H = periods 中 description="1st-half" 的 stats
  2H = periods 中 description="2nd-half" 的 stats

加时赛（如果有）：
  合并所有 description 含 "extra" 或 "ET_" 的 period → ET
  → 如果有 ET_1ST_HALF + ET_2ND_HALF，合并为 ET = ET1H + ET2H
  → 如果只有 "extra-time"，直接作为 ET

加速率定义（基于 periods，粗粒度）：
  下半场加速率 = (2H.Total_Shots - 1H.Total_Shots) / max(1H.Total_Shots, 1) × 100
  加时加速率   = (ET.Total_Shots - 2H.Total_Shots) / max(2H.Total_Shots, 1) × 100
  绝对变化     = 后段射门 - 前段射门
```

#### 进阶：基于 trends 的分层窗口细粒度追踪

periods 只有 2-4 个粗段（1H/2H/ET），而 trends 提供了逐分钟累积数据。采用 **分层窗口粒度**（同 4.3.1）：

```
高频指标（5 分钟窗口，9 段）：
  45 (Ball Possession)     → 控球率曲线
  43 (Attacks)             → 进攻累积线
  44 (Dangerous Attacks)   → 危险进攻累积线

低频指标（15 分钟窗口，6 段）：
  42 (Total Shots)         → 射门累积线
  窗口：0-15, 15-30, 30-45, 45-60, 60-75, 75-90

每段计算：
  segment_shots[t] = cumulative[end] - cumulative[start]
  segment_possession[t] = 该窗口内控球率的平均值

输出：
  "shot_segments":      [4, 2, 5, 3, 1, 4]       ← 每 15 分钟射门
  "attack_segments":    [18, 23, 20, 15, 17, 21]  ← 同上
  "possession_trend":   [72, 70, 68, 79, 75, 62, 58, 55, 52]  ← 每 5 分钟控球率，9 段
```

**优势**：periods 只能告诉你"下半场射门多了 37%"，trends 能告诉你"射门从 30 分钟开始逐步攀升，60-75 分钟峰值，75-90 骤降"——这才是真正的节奏曲线。

#### 判定逻辑

```
match-relative 判定：
  双方下半场均加速 → 不是谁"猛冲"，而是场面更开放了
  双方下半场均减速 → 不是谁"体力衰竭"，而是比赛趋于保守/体能同步下降
  一方加速一方减速 → 才说明战术/体能出现分化

综合判定（三层交叉验证）：

  1. 低基数过滤：
     上半场射门 < 4 → 百分比不可靠，只看绝对变化
     abs(绝对变化) ≤ 1  → "射门节奏稳定"（跳过低百分比判定）

  2. Match-relative 对比：
     Gap = 主队加速率 - 客队加速率
     |Gap| > 50pp（百分点）→ 双方分化显著，高方才是真正在加速/减速
     |Gap| ≤ 30pp         → 双方同向变化，用共同标签

  3. 比分感知：
     领先方 2H 射门降 > 30% 且 领先进球数 ≥ 2 → 追加"主动收力"（不是体能问题）
     落后方 2H 射门升 > 30% 且 下半场未进球    → 追加"猛冲无果"（压上了但没打进）

最终标签（仅限常规时间 1H→2H）：
  一方加速率 > 50% 且 Gap > 50pp 且 上半场射门 ≥ 4 且 非领先方 → "下半场猛冲"
  一方加速率 < -40% 且 Gap > 50pp 且 上半场射门 ≥ 4 → 
    └ 若该方领先 ≥ 2球 → "主动收力——领先后不想踢了"
    └ 否则             → "体力衰竭——上半场透支了下半场的体力"
  双方 |Gap| ≤ 30pp 且 双方加速率 > 20% → "下半场提速——双方都放开了踢"
  双方 |Gap| ≤ 30pp 且 双方加速率 < -20% → "下半场降温——比赛趋于保守"
  其余                                   → "平稳节奏——上下半场一致"

加时赛加速率（如果有 ET）：
  一方 ET 加速率 > 30% 且 射门绝对增长 ≥ 2  → "加时赛体能优势——进入加时后攻势反超"
  一方 ET 加速率 < -40% 且 射门绝对减少 ≥ 2 → "加时赛体能崩盘——常规时间已耗尽体力"
  双方 ET 射门 ± 相同的幅度                  → "加时赛双方同步——都在坚持"
  其余                                       → "加时赛节奏平稳"
```

**为什么这里 match-relative 尤其重要**：一场 4-3 的进球大战，双方射门可能都在下半场大幅增加——不是某一队"猛冲"，而是比赛本身在下半场失控了。一场 0-0 的闷平，双方射门都在下半场减少——不是某一队"体力衰竭"，而是双方都默认接受了平局。

### 5.2 压迫衰减追踪 (PPDA Segment Tracking)

PPDA 不是一成不变的——高位压迫的球队随着体能下降，PPDA 会逐段上升（压迫变松）。时段 PPDA 追踪直接回答"压迫能维持多久"。

> ⚠️ **PPDA 衰减率的百分比本身是合理的绝对值指标**（体能衰退是生理规律，不管对手是谁，PPDA 翻倍都意味着压迫力陡降）。但需要和 **PPDA 绝对值门槛** 交叉验证。

#### 数据来源（同 5.1）

从 `periods.statistics` 每段 period 提取：

```
PPDA_period = 对手.Total_passes / (本方.Tackles + 本方.Interceptions + 本方.Fouls)

period 对应关系：
  1H  = description="1st-half"
  2H  = description="2nd-half"
  ET  = 合并所有 description 含 "extra"/"ET_" 的 period（同 5.1 逻辑）
```

#### 计算逻辑

```
常规时间 PPDA 衰减（基于 periods，粗粒度）：
  1H_PPDA = 对手.Total_passes / (本方.Tackles + 本方.Interceptions + 本方.Fouls)
  2H_PPDA = 同上
  PPDA 衰减率 = (2H_PPDA - 1H_PPDA) / 1H_PPDA × 100（正值=压迫变松）

加时赛 PPDA 衰减（如果有 ET）：
  ET_PPDA = 同上
  ET 衰减率 = (ET_PPDA - 2H_PPDA) / 2H_PPDA × 100
```

#### 进阶：基于 trends 的 PPDA 逐窗口追踪 + 衰减拐点定位（15 分钟窗口）

periods 只能告诉你"下半场 PPDA 涨了 40%"，trends 可以告诉你"PPDA 在第 58 分钟突然从 4.3 跳到了 9.1——压迫就在那一刻崩溃了"。

> ⚠️ PPDA 的窗口粒度固定为 15 分钟（同 4.3.1 低频指标），因为抢断/拦截/犯规合计每 5 分钟窗口常有 0 值导致分母为零。传球可以用 5 分钟但 PPDA 需要防守动作分母。

```
trends 所需 type_id（全部可用，实测 fixture 19683241）：
  80 (Total passes)     → 逐分钟累积传球数
  78 (Tackles)          → 逐分钟累积抢断
  100 (Interceptions)   → 逐分钟累积拦截
  56 (Fouls)            → 逐分钟累积犯规

  68~79 pts / team for passes; 8~19 pts for defensive actions

窗口切分（6 段 15 分钟 + 加时）：
  0-15, 15-30, 30-45, 45-60, 60-75, 75-90, ET

每段 PPDA 计算：
  段内传球数 = 累积传球[end] - 累积传球[start]
  段内防守动作 = (累积抢断[end]-累积抢断[start]) + (累积拦截[end]-累积拦截[start])
                 + (累积犯规[end]-累积犯规[start])
  segment_PPDA[t] = 对手段内传球数 / max(本方段内防守动作, 1)

衰减拐点检测：
  正常 PPDA 波动范围（用前半场 mean ± 1σ 界定）
  当某个窗口的 PPDA 连续两次 > 前半场均值的 1.5 倍 → 标记为"衰减拐点"
  输出拐点发生的时间窗口 + 拐点前后的 PPDA 值

输出示例：
  "ppda_segments": [4.1, 4.5, 3.8, 5.2, 9.1, 11.4, 14.2]  ← 每 15 分钟的 PPDA
  "decay_breakpoint": {
    "window": "60-75min",
    "before_ppda": 5.2,
    "after_ppda": 9.1,
    "narrative": "压迫在第 60-75 分钟窗口崩溃——PPDA 从 5.2 跳至 9.1"
  }
```

**为什么拐点定位很有价值**：单一的数字"PPDA 衰减率 +47%"可以告诉你压迫力下降了。但拐点定位告诉你它是在什么时候降的——如果是 75-90 分钟（临终场），那是体能极限；如果是 45-60 分钟（中场休息刚回来），那是中场休息打断了压迫节奏；如果是进球后立刻降，那是有意收力而非体能问题。

#### 交叉验证判定（PPDA 绝对值门槛 + 衰减率 + 比分感知）：

```
  1. 绝对值门槛：
     1H_PPDA > 15 → 上半场就没压迫，不适用衰减率分析
     → 判定为"全场无压迫倾向"

  2. 衰减率判定（仅对 1H_PPDA ≤ 12 的队伍生效）：
     衰减率 > 50% 且 2H_PPDA > 12  → "压迫崩塌——上半场的压迫体系在下半场彻底瓦解"
     衰减率 > 50% 且 2H_PPDA ≤ 12  → "压迫衰减但仍在坚持——体能下降但战术底线没破"
     衰减率 25~50%                 → "体能滑坡——压迫力打折扣"  
     衰减率 10~25%                 → "正常衰退——高强度比赛的合理代价"
     衰减率 -10~10%                → "压迫稳定——全场强度一致"
     衰减率 < -10%                 → "越压越凶——下半场压迫反超上半场"

  3. 比分感知（追加说明）：
     衰减率 > 25% 且 该方领先 ≥ 2 球 → 追加"（也可能是有意收力）"
     衰减率 < -10% 且 该方落后        → 追加"（追分心态驱动的战术加码）"

  4. 加时赛 PPDA（如果有 ET，仅对 2H_PPDA ≤ 12 的队生效）：
     ET 衰减率 > 30% 且 ET_PPDA > 15 → "加时赛压迫瓦解——体能已到极限"
     ET 衰减率 > 30% 且 ET_PPDA ≤ 15 → "加时压迫下降但仍保持阵型"
     ET 衰减率 < 0% 且 ET_PPDA < 10  → "加时赛体能怪物——压迫不降反升"
     其余                             → "加时压迫稳定"
```

### 5.3 关键事件冲击

> **方法论**：对每个事件取「事件前 10 分钟窗口」和「事件后 10 分钟窗口」，对比同一指标的变化幅度。仅当变化超过该场比赛正常波动范围（全场相邻 10 分钟窗口的标准差 × 2）时才触发信号，以此排除随机波动。

| 事件 | 对比指标 | 触发条件 | 走势信号 |
|------|------|------|------|
| 进球 | 对方在前后窗口的 xG 累计 | 后窗口 xG > 0.3 且占全场对方 xG 比例 > 15% | "进球后的被动——被打懵了" |
| 红牌 | 红牌方在前后窗口的控球率 | 后窗口控球率降至前窗口的 60% 以下 | "红牌后的战术崩塌" |
| 红牌 | 同上 | 后窗口控球率 ≥ 前窗口控球率（与预期反向） | "少打多反而更团结" |
| 换人 | 换入球员所在队在前后窗口的进球 | 后窗口有进球且进球者是换入球员 | "换人奇效" |
| 乌龙球 | 乌龙球方在前后窗口的球权丢失次数 | 后窗口球权丢失 > 前窗口 × 1.5 | "乌龙球的心理重创" |
| 黄牌 | 该球员在前后窗口的对抗成功率 | 后窗口成功率 < 前窗口 × 0.7 | "黄牌绑住手脚" |

> **为什么不是「点球罚失 / VAR」**：点球罚失后射门减少可能是回归均值（点球本就是进攻高潮的终点）；VAR 暂停后节奏变化的方向不确定，且与 VAR 发生场景（禁区对抗强度）容易混淆。这两个事件的因果链不够干净，暂不纳入。

### 5.4 节奏主导权切换

从 trends 数据（逐分钟 type_id=45 控球趋势）检测：

```
主导方判定（替代固定阈值 55%）：
  每个 5 分钟滚动窗口，两队控球率差值 > 10%，且持续 ≥ 5 分钟
  → 高的一方为该时段「主导方」

节奏切换次数 = 主导方发生改变的次数

判定：
  切换 ≥ 4 次  → "大起大落——双方都曾掌控但没人能守住"
  切换 2~3 次  → "有一方拿到主动权后基本稳住"
  切换 0~1 次  → "单边主导——从头到尾一方说了算"
  始终无主导方  → "均势拉锯——没有一方真正掌控过比赛节奏"
```

> **为什么不用 55%**：固定阈值对强队太宽容（65% 才算掌控？），对弱队不可能触及。用「两队差值 > 10% 且持续」的判定对任何球队风格都公平，且过滤掉了 51%↔49% 的噪声抖动。

## 6. Layer 3：效果判定 — 战术奏效了吗？

> **本质**：把 Layer 1 的战术选择和 Layer 2 的比赛走势结合起来，判断每个战术决策的产出效率。这才是"控球效率"和"对抗强度"该待的地方——它们是验证指标。

### 6.1 进攻执行效果 — 维度 ROI

> **与 Layer 1 保持一致**：不依赖「短传控制」「长传急攻」这类固定标签。Layer 1 的代码层输出原始指标值（long_ball_ratio / cross_ratio / final_third_pass_ratio 等），Layer 3 在同一套维度上做 ROI 验证。每个维度对所有球队都计算，但只有在某维度上投入显著（比对手高 1.5x 以上）时才纳入评分——投入少的不算"该战术没打出"，只是没选这条路。

| 维度 | 投入指标（来自 Layer 1） | 产出指标（ROI） | 奏效 | 失败 |
|------|------|------|------|------|
| 控球 | 传球总数多 + 控球率高 | **控球 ROI** = xG / passes_total | > 0.025 → 传球在制造威胁 | < 0.010 → 控球只是倒脚 |
| 长传 | long_ball_ratio 高 | **长传 ROI** = 长传成功后 15s 内形成射门的次数 / long_balls | ROI 高于对手 1.5x | 长传多但射门转化率垫底 |
| 传中 | cross_ratio 高 | **传中 ROI** = 传中成功形成射门的次数 / crosses | 传中→射门转化 > 25% | 传中多但头球成功率 < 30% |
| 渗透 | final_third_pass_ratio 高 | **渗透 ROI** = 禁区内射门 / 射门总数 | 禁区内射门占比 > 55% | 禁区外射门 > 50%（进不去） |
| 直接性 | forward_ratio 高 + passes_per_shot 低 | **转换 ROI** = xG / (passes_total / attacks) | xG 和进球数匹配 | 转换多但 xG 远低于进球（运气） |

> **设计原理**：不是"你是短传控制队→检查你的控球 ROI"，而是"你的长传比高出对手 2.67 倍→你在长传维度投入巨大→检查你的长传 ROI 对不对得起这个投入"。每个球队在 5 个维度上都会得到分数，最终加权合成进攻执行总分。

### 6.2 防守执行效果 — 维度 ROI

同样不依赖标签，基于 Layer 1 的 PPDA / high_press_ratio / clearance_ratio 等原始值逐维度验证：

| 维度 | 投入指标 | 产出指标（ROI） | 奏效 | 失败 |
|------|------|------|------|------|
| 压迫强度 | PPDA 低（比对手低 1.5x 以上） | **压迫 ROI** = 对方传球成功率 / 对方全场平均 | 对方传球成功率降至 75% 以下 | 对方传球成功率 > 82%（压迫被传球化解） |
| 压迫持续性 | PPDA 衰减率 | 已有衰减率，本身就是效果指标 | 衰减率 < 15%（全场压迫在线） | 衰减率 > 30%（上半场猛下半场松） |
| 高位倾向 | high_press_ratio 高 | **高位 ROI** = 前场抢断直接导致射门的次数 / 前场抢断 | 转化率高 → 高位抢断有杀伤 | 转化率低 → 高位抢断后自己也拿不住 |
| 蹲坑深度 | PPDA 高 + clearance_ratio 高 | **蹲坑 ROI** = 对方 xG/shot（越低越好） | xG/shot < 0.08（只给低质量射门） | xG/shot > 0.15（蹲坑被打穿） |
| 拦截覆盖 | interceptions / 对方传球次数 | **拦截 ROI** = 拦截后 10s 内形成反击射门的比例 | 比例高 → 拦截是进攻起点 | 比例低 → 拦截只是把球踢出去 |

> **PPDA 时段追踪**对所有 PPDA 显著低的球队生效（而非只对某标签），判定标准同上。

### 6.3 核心判定公式

```
维度得分（连续值，替代 ±1）:
  投入权 = min(Gap / 1.5, 2.0)           → 投入越极端，该维度越重要
  效果值 = (实际ROI - 失败阈值) / (奏效阈值 - 失败阈值)   → 映射到 [-1, 1]
          · > 0  → 偏向奏效
          · < 0  → 偏向失败
          · 在失败阈值和奏效阈值之间线性插值（不强制非此即彼）
  维度得分 = 投入权 × 效果值

进攻/防守执行总分 = Σ 所有触发维度的得分   → 值域约在 [-10, 10]

二值判定:
  总分 > 0   → ✅ 奏效（综合产出为正）
  总分 ≤ 0   → ❌ 失败（综合产出为负或零）
  仅 1 个维度触发且得分在 [-0.5, 0.5]   → ➖ 不判定（投入方向不够清晰）
```

**综合标签**：

| 进攻执行 | 防守执行 | 综合标签 |
|:---:|:---:|------|
| ✅ 奏效 | ✅ 奏效 | "战术完胜——攻防两端均按计划运行" |
| ✅ 奏效 | ❌ 失败 | "攻得漂亮，守得狼狈——一个拳头打人一个拳头挨打" |
| ❌ 失败 | ✅ 奏效 | "战术保守但有效——不漂亮但实在" |
| ❌ 失败 | ❌ 失败 | "战术破产——两头都不占" |
| ➖ 不判定 | ➖ 不判定 | "战术意图不明显——双方缺少明确的风格投入" |

> **对抗强度的位置说明**：对抗（duels / tackles）已作为 6.2 的「压迫强度」「高位倾向」维度的底层数据融入效果判定，不单独列为一个维度。PPDA 低的球队，对抗失败即压迫被摆脱，已经在「压迫 ROI」中体现；PPDA 高的球队，对抗数据本身就不追求量，不额外扣分。

## 7. Layer 4：教练博弈 — 谁在棋局上赢了？

> 保留 v1 的教练博弈框架，但用前三层数据重新喂养。

### 7.1 换人意图（不变）

| 换人时机 | 意图推断 |
|:---:|------|
| < 30' | 伤病被迫 / 战术重大失误 |
| 46'-60' | 中场纠错，主动求变 |
| 60'-75' | 对位调整，维持强度 |
| 75'-85' | 战术转向（追分 / 死守） |
| > 85' | 拖延时间 |

### 7.2 换人效果 → 用 Layer 3 的指标验证

```
换人效果分 = 换人后进攻执行分变化 + 防守执行分变化

正分 → 换人有效（换上了对的人或换下了错的人）
负分 → 换人失败（换人后反而更糟）
```

### 7.3 战术克制链

> **与 Layer 1 一致**：不依赖标签，基于维度投入的显著差异判定克制关系。逻辑是「甲方在维度 X 投入巨大，乙方在维度 Y 投入巨大，X 与 Y 之间存在克制/被克关系」。

**克制规则（基于维度组合）**：

```
进攻维度 vs 防守维度：

  渗透 (final_third_pass_ratio 高) vs 蹲坑 (PPDA 高 + clearance_ratio 高)
    → 渗透 +2 克制蹲坑（禁区前沿精细配合是蹲坑的死穴）
    → 蹲坑 +2 反克渗透（如果渗透 ROI 为负——打不进去就是被蹲坑封锁）

  传中 (cross_ratio 高) vs 蹲坑 (PPDA 高 + clearance_ratio 高)
    → 蹲坑 +2 克制传中（蹲坑体系下禁区头球解围是基本功）
    → 传中 +2 反克蹲坑（如果传中 ROI 为正——传中质量高，蹲坑也防不住）

  长传 (long_ball_ratio 高) vs 压迫 (PPDA 低)
    → 长传 +2 克制压迫（长传直接越过压迫线，高压来不及成型）
    → 压迫 +2 反克长传（如果压迫 ROI 为正——长传被拦截率高）

  控球 (passes_total 高 + forward_ratio 低) vs 压迫 (PPDA 低)
    → 压迫 +2 克制控球（后场控球越久，被逼抢风险越大）
    → 控球 +2 反克压迫（如果控球 ROI 为正——控球能遛开压迫）
```

> **克制方向由效果数据裁决**：区间分 > 0 的一方才算「真正克制成功」。克制积分的正负不是预设的，而是由 Layer 3 的效果判定结果动态决定——「应该克制」不等于「真的克制了」。

**克制总分**：

```
进攻克制分 = Σ（甲方进攻维度 vs 乙方防守维度的克制值，仅纳入双方 Gap 均 > 1.5x 的维度对）
防守克制分 = Σ（甲方防守维度 vs 乙方进攻维度的克制值）

最终克制总分 = 进攻克制分 + 防守克制分
  正分 → 战术对路，克制链成立
  负分 → 战术被克
  接近 0 → 风格错位——双方的强项不在直接对立的维度上
```

## 10. v1 vs v2 对比总结

| | v1 | v2 |
|------|------|------|
| 结构 | 6 个平级维度 | 4 层因果链 |
| 阈值方式 | **绝对阈值**（长传比 > 0.20 判定"长传急攻"） | **Match-Relative**（与对手的差距倍数判定，附带最低基线） |
| 压迫强度 | "抢断/对手触球"粗糙估算 | **PPDA（金标准）**，match-relative 对比，含 trends 逐窗口追踪 + 衰减拐点定位 |
| 控球效率 | 独立维度 | Layer 3 中作为"验证短传控制战术奏效与否"的指标 |
| 对抗强度 | 独立维度 | Layer 3 中按战术需求区分关键对抗 |
| 核心叙事 | "他们的进攻体系是 X，控球效率是 Y" | "他们选择了 X 战术 → 场上走势是 Y → 执行效果是 Z → 战术成功了/失败了" |
| 话题性 | 靠对立面制造（A 的长传 vs B 的短传） | 靠**意图与现实的背离**制造（"想传控但传了个寂寞"）+ PPDA 衰减率制造（"压迫纸老虎——上半场凶猛下半场散架"） |
| 数据驱动 | 每个维度独立计算 | 先定战术画像，再用数据验证画像是否落地 |
