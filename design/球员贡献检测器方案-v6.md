# 球员贡献检测器方案 v6 — 两层叙事模型

> 设计日期：2026-06-08  |  状态：开发中
>
> **核心升级**：在 v5 七维贡献模型基础上，新增「角色推断层」，形成「贡献→角色」两层叙事体系。
>
> 指标映射参考：[SportMonks统计指标全集.md](./SportMonks统计指标全集.md)

## 1. 两层叙事模型

### 1.1 设计理念

```
第一层：贡献检测 → 定量回答 「做了什么，做得好不好」
  输入：66项球员级指标
  输出：C1~C7 各维度 Z-score 综合分 + 原始指标明细

第二层：角色推断 → 定性回答 「承担了什么角色，做得怎么样」
  输入：6维贡献向量 (C1~C6) + 位置(G/D/M/F)
  输出：角色名 + 角色叙事描述
```

### 1.2 与 v5 的区别

| | v5 | v6 |
|------|------|------|
| 贡献检测 | C1-C7 七维模型 | C1-C7 七维模型（不变） |
| captain/rating | 参与 C3 | **移除**，C3 从10项→8项 |
| 输出 | 贡献分 + 标签 | 贡献分 + 原始指标 + 角色 |
| 叙事 | 无 | **角色推断 + 叙事生成** |

|------|:---:|------|

| 直红 | -4.0 | card event |

## 3. 第二层：角色推断

### 3.1 设计哲学

角色的本质是**贡献向量的聚合表达**。例如：
- C4↑↑(防守铁闸) + C2↑(长传) + C3↑(控球) = 不是蹲坑中卫，而是**出球后卫**
- C3↑↑(节拍器) + C4↑↑(扫荡) + C5↑↑(对抗) = 不是单纯节拍器，而是**全能中场**

### 3.2 角色原型向量

每个角色定义一个 6 维理想贡献向量：


### 3.3 角色推断算法

```python
def infer_role(player_vector: dict, position: str) -> RoleResult:
    """用余弦相似度匹配最接近的角色原型"""

    candidates = [r for r in ROLE_PROTOTYPES
                  if r.valid_for(position)]
    best = max(candidates, key=lambda r:
        cosine_similarity(player_vector, r.prototype_vector))

    return RoleResult(
        name=best.name,
        confidence=cosine_similarity(...),
        narrative=generate_role_narrative(player, best),
    )
```

### 3.4 角色叙事模板

```
{球员名}本场承担了{角色名}的角色。
{强项1描述}，{具体数据}；
{强项2描述}，{具体数据}；
{弱项描述 — 中性语气，不贬低}。
```

示例：
> 马尔基尼奥斯本场承担了**出球后卫**的角色。防守端以5.2分领跑全队（解围7次、拦截4次、封堵2次），同时推进贡献高达4.8分（队内第2），7次长传5次成功，多次从后场直接发动反击。进攻贡献1.2分偏低，符合该角色定位——他的主要任务是防守+出球，而非前插得分。

### 3.5 角色推断的"自信度"说明

- confidence ≥ 0.9：角色特征非常明显，原型高度匹配
- confidence 0.7~0.9：有明确的角色，但可能有些均衡
- confidence < 0.7：球员表现较均衡，可能匹配不到明确角色 → 返回 `均衡型{位置}`

## 5. 数据流更新

```
run_v6(lineups, home_id, away_id, score, events)
    │
    ├── 解析 lineups → PlayerData[]
    ├── 解析 events → EventBonuses
    │
    ├── 第一层：贡献检测 ──────────────────────────
    ├── C1 进攻  → zscore_composite(外场, 15项)
    ├── C2 推进  → zscore_composite(外场, 12项)
    ├── C3 控制  → zscore_composite(外场, 8项)
    ├── C4 防守  → zscore_composite(外场, 10项)

    ├── C6 关键事件 → 事件评分
    └── C7 门将  → 四维 per-90 (G only)
    │
    ├── 汇总：每球员贡献向量 {C1:score, C2:score, ...}
    │
    └── 第二层：角色推断 ──────────────────────────
        └── 余弦相似度 → 角色名 + 叙事
```

## 7. 已知限制

| 问题 | 影响 | 处理 |
|------|------|------|
| 出场<15分钟的球员 | Z-score失真 | 跳过，标记N/A |
| 门将的外场贡献维度 | 与外场球员模式不同 | C3参与，其他标GK |
| Z-score被极端值影响 | 一人独大时全队偏低 | 可接受——反映一人带队的现实 |
| 角色原型是人工定义 | 主观性 | 后续可通过多场比赛数据校准 |
